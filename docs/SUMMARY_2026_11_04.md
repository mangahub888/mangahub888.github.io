# 📊 สรุปงานประจำวันที่ 4 พฤศจิกายน 2569 (2026-11-04)
> **MangaHub Multi-Platform Financials & Automated Growth Tracking System**  
> *บันทึกสรุปการพัฒนาและขึ้นระบบจริง (Production Release)*

---

## 🌟 ภาพรวมความสำเร็จ (Executive Summary)
ในรอบวันนี้ ได้พัฒนาและแก้ไขระบบวิเคราะห์สถิติและการเงินข้ามแพลตฟอร์ม (**ReadRealm**, **Kairew**, **Chaply**) บนหน้าระบบการเงิน (`FinancialsView.tsx`) และระบบเก็บสถิติอัตโนมัติเบื้องหลัง (`tools/chaply_growth_tracker.py`):
1. รวมข้อมูลมังงะเรื่องเดียวกันข้าม 3 แพลตฟอร์มเป็นแถวเดียว (+ กันอย่างสมบูรณ์)
2. เพิ่ม Badge ตรวจสอบสถานะการลงมังงะ 3 แพลตฟอร์มพร้อมกัน `[Readrealm/][Kairewx][Chaplyx]`
3. เพิ่มคอลัมน์ยอดขายรายตอน 7 ตอนล่าสุด หารเฉลี่ย (`฿.../ตอน`)
4. ระบบตรวจจับจำนวนตอนไม่เท่ากัน พร้อม Badge เตือนสีแดง `⚠️ ... ตอน` และปุ่มตัวกรองด่วน `⚠️ ตอนไม่เท่ากัน (53)`
5. เชื่อมต่อ API รายได้รายตอนของ **Chaply** ดึงยอดขายและ 7 ตอนล่าสุดสำเร็จทั้งพอร์ต 67 เรื่อง

## 🛠️ รายละเอียดการพัฒนาและการแก้ไข (Detailed Implementations)

### 1. ระบบรวมมังงะเรื่องเดียวกันข้ามแพลตฟอร์ม (+ กันในแถวเดียว)
- **Title Normalization (`normalizeMangaTitle`)**: ทำความสะอาดและจับคู่ชื่อเรื่องมังงะข้ามเว็บ ตัดภาษาอังกฤษ ตัวอักษรพิเศษ และจับคู่ชื่อเรื่องที่มีความแปรผัน (เช่น *อาจารย์ ศิษย์บ้าขอกบฏนะขอรับ*)
- **ผลการรวม**: ยุบรวมจาก 382 รายการดิบ เหลือ **243 เรื่องเฉพาะ (Unique Titles)** ในโหมด `🌟 รวมทุกแพลตฟอร์ม`
- **การบวกยอดขายและยอดวิว**:
  - ยอดขายรวม: นำยอดขายสะสมของทุกเว็บที่มังงะเรื่องนั้นวางจำหน่ายมารวมกัน
  - ยอดวิวรวม: รวมยอดวิวจากทุกเว็บ
  - การเติบโต 7 วัน / 30 วัน: คำนวณ Delta และ % Growth ข้ามแพลตฟอร์มอย่างแม่นยำ

### 2. Badge ตรวจสอบสถานะแพลตฟอร์ม `[Readrealm/][Kairewx][Chaplyx]`
- แสดงสถานะในคอลัมน์แพลตฟอร์มพร้อมกัน 3 เว็บ:
  - **มีลงเว็บนั้น**: แถบสีประจำเว็บ พร้อมเครื่องหมายขีดถูกสีเขียว `/` (เช่น `Readrealm /`, `Kairew /`, `Chaply /`) พร้อม Tooltip แสดงยอดขายและยอดวิวของเว็บนั้น
  - **ไม่มีลงเว็บนั้น**: แถบสีเทาเข้มโปร่งแสง พร้อมเครื่องหมายกากบาทสีแดง `x` (เช่น `Chaply x`)

### 3. คอลัมน์ยอดขายรายตอน 7 ตอนล่าสุด หารเฉลี่ย
- **แทนที่คอลัมน์ยอดวิวรวมเดิม**: ปรับเปลี่ยนเป็น **"ยอดขายรายตอน 7 ตอนล่าสุด / หารเฉลี่ย / ตอน"**
- **การแสดงผล**:
  - ตัวเลขหลัก (สีทองเด่น Font Mono): ยอดขายเฉลี่ยต่อตอนของ 7 ตอนล่าสุด (`฿.../ตอน`) คำนวณจาก `sales_7_chapters / min(7, chapters_count)`
  - ตัวเลขย่อยด้านล่าง: ยอดขายรวม 7 ตอนล่าสุด (`รวม ฿...`) ควบคู่กับยอดวิว (`• วิว ...`)
- **แก้ปัญหาค่าแสดงผลเป็น `-`**: ผูกตัวแปร `display_sales_7_chapters` และ `display_views_7_chapters` ในตารางทั้งโหมดรวมเรื่องและโหมดแยกรายการ แสดงค่าเงินจริงถูกต้อง 100%

### 4. ระบบตรวจจับจำนวนตอนไม่เท่ากันข้ามแพลตฟอร์ม
- **ตรวจจับความคลาดเคลื่อน (Mismatch Detection)**:
  - หากมังงะเรื่องเดียวกันมีจำนวนตอนในแต่ละเว็บไม่ตรงกัน (เช่น ReadRealm 211 ตอน แต่ Kairew 212 ตอน):
    - แสดง **Badge สีแดง `⚠️ {ตอนสูงสุด} ตอน`**
    - แสดงป้ายระบุจำนวนตอนย่อยของแต่ละเว็บด้านล่าง (เช่น `RR:211`, `KW:212`)
  - หากจำนวนตอนตรงกันทุกเว็บ: แสดง Badge สีมาตรฐานพร้อมข้อความสีเขียว `✓ เท่ากันทุกเว็บ`
- **ปุ่มตัวกรองด่วน**: เพิ่มปุ่มกรอง **`⚠️ ตอนไม่เท่ากัน (53)`** บนแถบตัวกรองสถานะด้านบน เพื่อคลิกดูเฉพาะเรื่องที่มีปัญหาตอนไม่ตรงกันได้ทันที

### 5. วิศวกรรมย้อนรอยและเชื่อมต่อ API รายได้รายตอนของ Chaply
- ตามคำแนะนำของผู้ใช้: *"chaply ยอดเหรียญ ต้องกดแก้ไข จะอยู่ในส่วนของรายได้ รายตอน"*
- ได้ตรวจสอบหน้าจัดการตอน `/writer/contents/{comic_id}/edit` -> แท็บ `จัดการตอน` พบ Endpoint ภายใน:
  ```http
  GET https://api.chaply.net/api/writer/content-episodes/group/{comic_id}?pageIndex=0&pageSize=100&includeSales=true
  ```
- คืนค่า `total_revenue` (รายได้รายตอน), `total_purchases` (จำนวนครั้งที่ซื้อ), `total_views` ของทุกตอน
- อัปเดต `tools/chaply_growth_tracker.py` ดึงยอดขายและ 7 ตอนล่าสุดของการ์ตูนทั้ง 67 เรื่องบน Chaply (ยอดสะสมพอร์ต Chaply รวม ฿8,270.91) และซิงค์เข้า Frontend สำเร็จ
